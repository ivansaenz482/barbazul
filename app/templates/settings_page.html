Nombre del sistema

Es el nombre que aparece en la barra del menú, en los títulos y en el login. Úsalo para personalizarlo por cliente (ej. "Sistema de Facturación Los Andes").

Venta sin stock

Define qué hace el sistema cuando intentas vender más unidades de las que hay en la bodega.

Desactivado: bloquea la venta si no hay stock suficiente (más seguro).
Activado: permite la venta, deja el stock en 0 y muestra una advertencia.
Programa de puntos / fidelidad

Los clientes ganan puntos al comprar y pueden canjearlos como descuento en una venta.

Ejemplo: 1 punto por dólar y $0.01 por punto = cliente con $100 comprados tiene $1 de descuento.
Consulta de Cédula / RUC (API automática)

Pega aquí la URL y el token de tu API (de preferencia la gratuita). Al pulsar “Validar / Consultar” en el cliente, el nombre se llenará solo. Usa {cedula} o {ruc} en la URL donde va el número.

Si no pones token y tu API es pública, igual funciona.
